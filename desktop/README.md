# Sésamo Desktop (macOS)

A native desktop shell for your self-hosted **Sésamo** vault, built with
[Tauri v2](https://tauri.app). It gives you a standalone macOS app (dock icon,
its own window, native copy/paste and keyboard shortcuts) instead of a browser
tab — while changing **nothing** about the security model.

Prebuilt universal `.dmg` files (Apple Silicon + Intel) are published on
[GitHub Releases](https://github.com/pmoncadaisla/maspassword/releases) by CI on
every `v*` tag. They are unsigned; see the install note in the root README
(`xattr -cr /Applications/Sesamo.app`). The rest of this document is for
building from source.

## How it works (and why it stays zero-knowledge)

The Sésamo web app talks to its server with **relative** paths
(`/auth/mode`, `/api/...`) and **same-origin** session cookies. To make that work
unchanged, the desktop app does not bundle or rewrite the web UI. Instead:

1. A small bundled **launcher** window asks for your server URL
   (e.g. `https://vault.example.com`).
2. The Rust side opens a second **vault** window pointed directly at that origin
   with `WebviewUrl::External`, so the real web app loads exactly as it would in
   a browser — relative API calls and cookies resolve against your server.
3. The server URL is remembered in the app config dir so you only enter it once.

All key derivation and AES-GCM encryption still happen inside the webview, on
your machine. The desktop shell never sees your master password or any plaintext,
and it grants the remote vault window **no** Tauri IPC access (see
`src-tauri/capabilities/default.json`). It is, deliberately, just a well-behaved
browser tab for one origin.

## Prerequisites

- **Rust** (stable): https://rustup.rs
- **Node.js** 18+ and npm
- **Xcode Command Line Tools**: `xcode-select --install`

## Setup

```bash
cd desktop
npm install            # installs @tauri-apps/cli
npm run icons          # generate the macOS icon set from app-icon.png
```

`npm run icons` runs `tauri icon app-icon.png`, which populates
`src-tauri/icons/` with all the sizes/formats the bundler needs (including
`icon.icns`). Those generated files are git-ignored; only the source
`app-icon.png` is committed. Swap in your own 1024×1024 PNG to rebrand.

## Develop

```bash
npm run dev            # tauri dev — hot-reloads the launcher, opens the app
```

## Build a distributable

```bash
npm run build          # produces a .app and .dmg under src-tauri/target/release/bundle/
```

For a signed/notarized build, set the usual Apple signing environment variables
(`APPLE_CERTIFICATE`, `APPLE_ID`, `APPLE_PASSWORD`, `APPLE_TEAM_ID`) before
`npm run build`; see the Tauri macOS distribution guide.

## Notes & known limitations

- **HTTP servers:** macOS App Transport Security restricts plain `http://` loads
  in a webview. `http://localhost` works for local development; for a remote
  server use `https://`. Supporting arbitrary `http://` hosts would require an
  ATS exception in the bundle's `Info.plist`.
- The launcher offers a remembered server without auto-connecting, so an
  unreachable server never leaves you staring at a blank window with no way back.
- "Use a different server" clears the saved URL and returns to the entry form.

## Layout

```
desktop/
  app-icon.png              source icon (1024×1024 recommended)
  package.json              npm scripts + Tauri CLI devDependency
  src/                      bundled launcher UI (local, trusted)
    index.html
    styles.css
    main.js
  src-tauri/
    Cargo.toml
    build.rs
    tauri.conf.json         window + bundle config
    capabilities/default.json
    src/main.rs             launcher/vault window logic + persistence
    icons/                  generated by `npm run icons`
```
